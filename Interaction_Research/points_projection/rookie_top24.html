Rookie Top 24 by Method

Every drafted rookie class from 2010 to 2022, ranked three ways by expected dynasty value in the default scoring and reference league. Current is today's tier method: tier odds times what past players in each tier scored. Rookie-year PPG and 3-year PPG project each player's own points per game and multiply the part above replacement by expected games. All three use the same post-draft inputs, stop-loss and discount, and every number is out-of-class: each class is scored by models that never saw it. The last board is the real top 24 in hindsight.
